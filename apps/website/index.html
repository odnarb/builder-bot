FAQ

Can I use it for free?

Yes. The Free plan includes up to 100 build requests each month.

Is it safe for kids?

It uses limits and checks to keep builds controlled, and setup works best with adult help.

When should I upgrade?

Upgrade when your monthly build requests keep hitting your current plan cap.

Do I need operator permissions?

For advanced actions, yes. Basic testing can start without full server-level control.

What are command blocks?

They are advanced automation tools in Minecraft used for more powerful scripted behavior.
